# 兩份 Deck 點用

## 一句講晒

- **v1《網紅推廣平台一覽》**：講市場上而家有咩平台、點樣運作。
- **v2《網紅推廣平台一覽v2》**：講我哋可以幫你起咩，主打市場上
  未見有人做嘅位（藍海）。

兩份分開用：v1 係背景資料，v2 先係正式 pitch。

## 分別

| | v1 | v2 |
| --- | --- | --- |
| 目的 | 市場背景、現有平台 | 我哋嘅方案 |
| 內容 | IG / 小紅書數據、五類平台、Collabstr、Kolr、AnyTag | 商戶痛點、市場空位、兩個方向、demo、風險、資助、我哋、問題 |
| 頁數 | 7 | 13 |
| 角色 | 開場或者補充資料 | 主 pitch |
| 幾時用 | 老細想了解現有點做 | 揀方向、傾合作 |

## v2 嘅藍海位

現有平台（外國同香港本地）大多只做到「幫你搵 KOL」。
我哋搵唔到有平台做到「到店核銷先收錢」。呢點喺 v2 第 3 頁。

**講嘅時候要小心：**

- 研究信心只係中低。講「我哋搵唔到」，唔好講「冇人做」。
- 最近嘅對手係 ShopBack Pay（有到店回贈，冇 KOL）同本地
  PopaRed、Try.Eat!、Look4KOL。
- 開會前最好自己上官網睇吓 HK-KOL、PopaRed、Try.Eat! 有冇加
  核銷功能。

## 點樣配合用

- **開會前：** 可以將 v1 send 俾老細做背景閱讀。
- **開會時：** 用 v2。
- **老細問「點解唔直接用 Collabstr / PopaRed？」：** 翻返 v1
  第 3 至 6 頁，講佢哋做乜、唔做乜，再接返 v2 第 3 頁。

## v2 每頁講乜

| 頁 | 內容 | 一句講稿 |
| --- | --- | --- |
| 1 | 封面 | 我哋想幫你做一個幫商戶帶客嘅平台。 |

| 3 | 市場空位 | 現有平台幫你搵 KOL，冇人幫你計成效。 |

| 7 | 兩個方向比較 | 兩個收錢方法唔同，睇你邊個適合。 |

## 兩個方向收費唔同

- **方向一：** 每次核銷抽佣，冇客上門就唔使俾。
- **方向二：** 軟件月費，或者按 post 數量收費。

老細如果問點解唔同，答：方向一係按成效，方向二係工具費。
