    ✦ PHASE 1 功能一覽

    八塊功能，一次過講清楚

    👥

    會員制

    付月費成為會員，解鎖更多 / 獨家著數 + 更高回贈比例。會員費係第一條收入。

    MEMBERSHIP
    🔗

    專屬 Share Link

    每人一條帶 tracking ID 嘅 link。朋友經 link 領券 / 用券，rebate 自動計返分享者。

    TRACKING LINK
    📊

    獎勵儀表板

    每筆 rebate 寫明狀態 + 原因（已入賬 / 凍結 / 被拒），每條 link 帶咗幾多客一眼睇晒。

    REWARD DASHBOARD
    🏔

    里程碑階梯

    帶夠客 → 額外 bonus（唔係取代單單 rebate）。永遠 show 進度：「你仲差 X 個客」。

    MILESTONES
    🎟

    抽獎券入著數易

    每 N 個客送 1 張抽獎券，自動入返著數易每週大抽獎——唔使自己起多個抽獎系統。

    RAFFLE TICKET
    🎯

    Mission 任務

    多步任務 + 進度（分享 5 次 2/5、邀請 3 個朋友 1/3），完成先獎。

    CHALLENGES
    📱

    到店 QR / Wallet Pass

    個人 referral QR 放喺錢包 pass，面對面推薦即刻變可追蹤 referral。

    QR + WALLET
    🛡

    防假（Fraud）

    自己帶自己唔計、突然爆量 hold 落嚟 review、退款 reverse。積分行先，出金留 Phase 2。

    FRAUD CONTROL

    ✦ 輕量商戶

    出一條「人人用得」嘅 link，睇邊個帶咗幾多客
